## 文档状态约定

- **已实现**：代码存在。
- **隔离验证**：临时配置、测试替身、HTTP 测试或隔离浏览器通过。
- **真实页面验证**：已在当前 Magpie 宿主中实际打开并记录结果。
- **已规划**：尚未实现，不得写成完成。

## 维护规则

- 根 `README.md` 保持为中文项目入口，不承载全部细节。
- 产品范围改 01，架构和执行改 02，状态和计划改 03。
- `03` 的迭代计划不得自动生成；只有 Ivy 明确确认目标、优先级和验收标准后才能写入。
- 新增长期决策使用 ADR；不要用状态文档覆盖已接受决策的历史背景。
- 所有“通过”“完成”结论应附命令、日期或隔离/真实环境说明。
