# 01 - 项目定位与范围

> 更新时间：2026-10-30

## 一句话定位

Skills Management 是 Magpie 的独立插件页，用于在 Windows 上整理和操作
Magpie Library 中的技能：给技能加多标签、控制已安装 Agent 的全局归属、查看
来源和本地目录，并为指定项目增加项目级技能。

它不替换 Magpie Library，不改写 Magpie 的页面源码，也不接管技能的安装、更新
和卸载流程。

## 目标用户与场景

- 目标用户：在 Windows 上同时使用多个 AI Agent、并通过 Magpie 管理技能的个人用户。
- 核心场景：
  - 技能数量增多后，用标签和搜索快速定位。
  - 查看某个技能启用了哪些当前已安装 Agent。
  - 一次完成某个技能的全局全开或全关。
  - 复制技能名、打开 Library 技能目录、打开技能来源。
  - 在某个本地项目中额外启用技能，同时不影响全局归属。

## 当前产品形态

- Magpie 插件页：入口位于 Magpie 的 Plugins/Extensions 区域。
- 页面运行方式：`page/boot.html` 读取 Magpie 主题与配置，再进入插件自己的本地服务页面。
- 本地服务：Bun HTTP 服务，只监听 `127.0.0.1`，默认端口 `3487`。
- 平台范围：Windows；WSL、远程 Agent 和跨平台支持不在当前范围。

## 当前范围

### 已实现并在隔离环境验证

- 技能浏览：全部、未分类、按标签筛选、按名称/描述/来源搜索。
- 多标签：一个技能可关联多个标签，标签数据独立保存。
- Agent 发现：只展示当前 Windows 环境中已安装、且 Magpie 支持 Skills 的 Agent。
- 全局归属：
  - 单个 Agent 开/关。
  - 当前可用 Agent 全开/全关。
  - 保留未安装 Agent 的历史归属，不因页面打开或全局切换自动删除。
- 技能卡片：
  - 原生 Agent 图标。
  - 来源行、GitHub 所有者头像。
  - 精确复制技能名。
  - 打开 Library 技能目录。
  - 打开原生或自定义网页来源。
- 项目：
  - 展示 Magpie 原生项目，原生项目视图保持只读。
  - 技能菜单可对原生项目做窄范围成员写入，保留其他隐藏或不支持的 Agent 归属。
  - 可注册插件自有项目，并用 Windows Junction 增加项目级技能。
- 安全边界：
  - 页面 capability + 短期写会话。
  - 仅回环地址、受限 Host/Origin、请求大小和写队列限制。
  - 桌面动作只接受固定动作和受控参数。

### 已实现但尚未完成真实 Magpie 页面验收

- 当前工作区中的体验升级尚未通过真实 Magpie 页面重新加载确认。
- 真实 Magpie 宿主下的主题、能力脚本、剪贴板、Explorer、默认浏览器和
  项目管理交互仍需在部署关卡中复验。
- 原生项目只允许“Add to project”菜单做成员变更；没有通用原生项目编辑能力。

### 明确不在当前范围

- 替换、修改或注入 Magpie Library 页面。
- 直接提供任意 Shell、任意文件路径或任意 URL 执行入口。
- 安装、更新、删除、编辑技能内容，或绕过 Magpie 的安装与同步机制。
- 自动扫描全盘、自动导入原生项目，或让插件项目与原生项目双向同步。
- 为项目建立“仅这些技能可见”的隔离配置；项目技能采用附加可用模型。
- 用复制目录代替 Junction，或通过管理员权限/开发者模式强行创建链接。
- WSL Agent、远程 Agent、macOS/Linux 支持。
- AI 自动修改技能归属或项目配置。

## 产品原则

- Magpie 是技能内容和全局 Agent 归属的权威来源。
- 插件只保存自己拥有的标签、自定义来源和插件项目元数据。
- 写入必须最小化；每次修改后都要重新读取实际状态，不能只看命令返回码。
- 原生项目成员写入必须备份、原子替换、执行 Magpie 同步并验证结果。
- 只删除插件证明拥有的 Junction；外部目录、冲突文件和原始 Library 技能必须保留。
- 未安装 Agent 的历史归属属于数据，不应被普通页面操作顺手清空。
- 共享目录造成的实际可用性必须如实展示，不能用独立勾选伪装成隔离。
- 文档中“已实现”“隔离验证”“真实页面验证”必须分开写。
