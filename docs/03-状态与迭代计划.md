## 已知限制与风险

### 兼容性

- Agent 显示名和 Skills 目录映射是针对当前 Magpie Windows Agent 目录维护的固定表。
- 历史记录包含 `0.1.2115/0.1.2120/0.1.2169`，2026-10-30 常驻实验使用
  `0.1.2185`；真实页面验收时需要再次确认当前版本、Agent 名称和 CLI 行为。
- 未知 Agent 只产生警告，不会自动成为可分配 Agent。

### 全局写入并发

- 原生资源库锁为进程内锁，插件 CLI 和独立辅助程序不能自动与原生进程共享。
- 即使修改不同技能，整个资源库的读取、修改和两次保存仍可能覆盖另一个
  进程的变更；本轮已在临时环境确定性复现。
- 插件队列、普通文件锁、点击合并及更快完成都不等于跨进程原子性。
- 常驻写入实验程序暂未接入；保留 CLI 路线也不能宣称这一风险已修复。

### 项目

- 原生项目只允许成员菜单的窄写入，不允许通用项目编辑。
- 插件项目不和原生项目同步，也不会自动接管已有原生项目。
- 多个 Agent 共享项目目录时，无法通过一个独立勾选制造目录级隔离。
- 项目如果被外部替换、移动或出现冲突，会进入只读状态，不会自动修复。
- 原生项目写入与 Magpie 其他写入进程之间没有共享锁；当前通过原始内容比对、
  文件锁、备份和同步回滚降低风险。

### 平台与动作

- 仅支持 Windows。
- 剪贴板、Explorer 和默认浏览器依赖 PowerShell 7。
- 不通过管理员权限、开发者模式或复制回退来强行完成 Junction。
- 共享目录和 `offHere` 会让“已勾选”与“实际可读”不完全等价，页面必须保留提示。

### 发布状态

- 原始插件已在真实 Profile 中安装。
